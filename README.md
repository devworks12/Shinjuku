# 新宿駅乗り換え3Dアプリ

新宿駅の乗り換えルートを、OpenStreetMap の実データから作った3D模型と高速POVで確認できる静的Webページです。
東京駅版（[norikae-warp](https://kokazkoko.github.io/norikae-warp/)）の新宿版として作りました。

- 地図データ: © OpenStreetMap contributors（ODbL）
- 経路・階・改札の情報は地図データからの推定を含みます。所要時間は目安です。

## できること
- 「乗ってきた路線」と「乗り換える路線・行き先」を選ぶと、その場でホームからホーム（または出口）までのルート候補をプレビュー。「出発進行」で POV 再生、「✕ 閉じる」「最初の画面へ」で最初の画面に戻る
- 路線の一覧は駅ナンバリングのアイコン付き（JY17・OH01・M08 など）。路線名やひらがなで検索もできる
  - ルート1（最短）・ベビーカー・車いす（階段・エスカレーターなし）・ルート2〜4（別の通路を使うルート）
  - それぞれに、経由する階・通路名、屋外を歩く距離、通る改札、所要時間の目安
- 3D模型: 通路（床・壁・天井）、階段・エスカレーター・エレベーター、改札機と改札名の看板、ホーム（点字ブロック・線路・柱・屋根）、主要ビル・通りの名前
- POV（一人称）再生: 案内カード（「地下1階の通路を進む　次：階段で…」）、進捗バー、ミニマップ。タップで一時停止、左右スワイプで戻す/進める。標準・高速・超高速
- 階ごとの表示切り替え、URL（`#from>to`）での経路共有

## 構成
```
index.html / css/style.css     画面
js/app.js                      three.js の模型・POV・ミニマップ・UI
js/model.js                    3D模型の組み立て（床・壁・天井・階段・改札・ホーム・看板）
js/route.js                    経路探索（ダイクストラ・ルート候補）と案内文（three.js 非依存）
data/station.json              tools/build_station.py が作る駅データ
data/raw/                      OSM 生データ（Geofabrik 関東抽出から切り出し）
tools/build_station.py         OSM → station.json 変換
tools/station_config.py        路線・番線・出口・改札名・手動補正
tools/test/routes.mjs          全路線ペアの経路テスト（node tools/test/routes.mjs [from] [to]）
.github/workflows/fetch-osm.yml  OSM データ取得と station.json 再生成（手動 / 毎月）
```

## データの作り方
1. GitHub Actions「Update station data」が Geofabrik の関東抽出をダウンロードし、新宿駅周辺を `osmium` で切り出して `data/raw/` に保存、`station.json` を作り直してコミットします（Actions タブから手動実行、または毎月1日に自動）。
2. 手元で作り直す場合は `python3 tools/build_station.py --report`（標準ライブラリのみ）。

変換のポイント:
- `level` タグ（無ければ通路名の「地下1階」などや `layer`）で階を決め、複数階にまたがる地点（エレベーター等）は階ごとに分けて縦につなぐ
- `barrier=turnstile` の点・線、「…;西改札」のような名前の通路を改札として扱う
- ホームから改札を越えずに行ける範囲を各社の改札内とする。OSM の改札の描き漏れに備えて、他社や改札外の名前が付いた通路は壁として扱い、それでも改札内と改札外が直接つながる箇所には推定の改札を入れる
- 通路の形は、駅の向きに合わせたマス目（0.8m）に通路の幅を塗って作り、3D表示では床・壁・天井にする
- 番線・行き先・出口位置・改札名・改札内の範囲は `tools/station_config.py` に手で設定（誤りがあればここを直して再生成）

## ローカルで見る
```
python3 -m http.server 8000
# → http://localhost:8000/
```
（three.js とフォントは CDN から読み込みます）
